# proof/audit/allowed.txt
#
# The allowed assumption cones of both public statements in Shrincs.theorem.
# Gate 4 checks the compiled probe against these names and provenance notes.
#
# The project declares no assumption. Every name below is a baseline
# inherited from SSProve, MathComp, CompCert, Flocq, VST or the standard
# library. The security statement bounds the forger's advantage by the
# advantages of six explicit reductions against the hash games, so the
# hardness of those games is the reader's premise, not an axiom here.
#
# Blank lines, comments and section headers are ignored when extracting names.
#
# A name is spelled here exactly as `Print Assumptions` prints it in
# probe.v's import context (shortest unambiguous qualid). That spelling
# is import-context dependent -- `Axioms.R` prints bare as `R` under
# different imports -- so each entry says what it IS, not just what it
# is called.
