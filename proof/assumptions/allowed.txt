# proof/assumptions/allowed.txt
#
# ONE allowlist, all three proof trees. assumptions/check.sh's gate 3
# (Print Assumptions cone diff) extracts one section per tree -- [model]
# for assumptions/model.v, [ssprove] for assumptions/ssprove.v, [vst] for
# assumptions/vst.v -- and diffs the compiled probe's actual axiom cone
# against that section only.
#
# Format: blank lines and `#` comments (whole-line, or trailing after a
# name) are ignored when extracting names, so every entry below carries a
# one-line provenance note; check.sh's TRUST SURFACE table sources those
# notes directly from here. Do not reorder/rename the
# `[model]`/`[ssprove]`/`[vst]` section headers -- check.sh looks for
# those literal lines.
